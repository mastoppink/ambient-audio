04Contoh audio dari browser

Dibuat di belakang layar, kira-kira dua kali lebih cepat dari durasinya. Volume sudah disesuaikan untuk YouTube. MP3 sekitar 5x lebih kecil dari WAV, jadi lebih cepat diunduh dan dibagikan.

05Judul & deskripsi YouTube

    Disusun dari suasana, suara melodi, kecerahan, bentuk lagu, dan durasi yang sedang dipilih. Durasi dan chapter mengikuti pilihan "Durasi video" di bagian 03. Versi Python membuat file .judul.txt dari audio yang sudah jadi.

    Encoder MP3: LAME (lamejs, lisensi LGPL, file terpisah di vendor/lamejs).

    File .toml berisi pengaturan yang sedang terdengar: warna suara, nada dasar, suasana, dan bentuk lagu. Urutan chord dan melodi di versi Python akan berbeda, karena tiap versi punya pengacak sendiri. Efek kilau (shimmer) hanya ada di versi Python.
